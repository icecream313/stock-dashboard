종합 투자 의견을 AI가 직접 분석해 줍니다
키는 이 기기의 브라우저에만 저장되며 서버로 전송되지 않습니다. 호출 비용은 본인 Anthropic 계정으로 청구됩니다. 키 발급: console.anthropic.com
Opus는 분석 품질이 가장 높고, Haiku는 빠르고 저렴합니다. 종합 의견은 짧아서 비용 부담이 크지 않습니다.
⚠️ API 키를 입력하지 않아도 모든 점수·인포그래픽은 규칙 기반으로 동작합니다. AI 연동은 '🤖 Claude 심층 의견'·'💬 대화형 질문' 기능에서만 사용되며, 생성된 의견 역시 투자 권유가 아닌 참고 자료입니다.
선택 해제한 섹션은 화면에서 숨겨집니다. 거시 지표·관심종목은 핵심이라 항상 표시됩니다. 설정은 이 기기에 저장됩니다.
관심종목 카드의 '목표가'를 입력하면, 현재가가 목표가에 도달했을 때 브라우저 알림을 보냅니다.
